# Chrome Extension Development - Key Learnings & Limitations

## 🚨 Critical Issues Discovered & Solutions

### 1. **Manifest V3 Offscreen API Configuration**

#### ❌ **WRONG** - Don't declare offscreen documents in manifest
```json
{
  "offscreen": {
    "documents": ["src/offscreen/offscreen.html"]
  }
}
```
**Error:** `Unrecognized manifest key 'offscreen'`

#### ✅ **CORRECT** - Use programmatic creation only
```json
{
  "permissions": ["offscreen"]
}
```

**Background script creates offscreen documents programmatically:**
```typescript
await chrome.offscreen.createDocument({
  url: chrome.runtime.getURL('src/offscreen/offscreen.html'),
  reasons: ['BLOBS', 'DOM_PARSER'],
  justification: 'Long-running analysis and LLM calls'
});
```

---

### 2. **Vite Build Configuration - Absolute vs Relative Paths**

#### ❌ **WRONG** - Absolute paths (default Vite behavior)
```html
<!-- Generated by default Vite config -->
<script type="module" crossorigin src="/popup.js"></script>
<link rel="stylesheet" href="/popup.css">
```
**Result:** JavaScript doesn't load, buttons don't work, silent failures

#### ✅ **CORRECT** - Relative paths for Chrome extensions
```typescript
// vite.config.ts
export default defineConfig({
  base: './',  // ← CRITICAL: Forces relative paths
  build: {
    // ... rest of config
  }
});
```
**Generated HTML:**
```html
<script type="module" crossorigin src="./popup.js"></script>
<link rel="stylesheet" href="./popup.css">
```

---

### 3. **Chrome Extension Context Limitations**

#### **Why Absolute Paths Fail:**
- Chrome extensions run in a **sandboxed extension context**
- No web server serves files from root `/`
- Extensions use `chrome-extension://` protocol
- Only relative paths resolve correctly to extension files

#### **Symptoms of Path Issues:**
- ✅ Extension loads without manifest errors
- ❌ Popup opens but buttons don't respond
- ❌ No console logs from popup script
- ❌ No JavaScript errors (silent failure)
- ❌ HTML loads but scripts/styles don't

### 4. **Debugging Chrome Extensions**

#### **Essential Debugging Steps:**

1. **Manifest Errors:**
   ```
   Right-click extension icon → "Manage extensions" 
   → Check for red error messages
   ```

2. **Popup Script Issues:**
   ```
   Right-click popup → "Inspect"
   → Console tab → Look for script loading errors
   ```

3. **Background Script Issues:**
   ```
   Extension management page → Extension details → "Inspect views: background page"
   ```

4. **Check Resource Loading:**
   ```
   DevTools → Network tab → See if scripts/CSS load with 200 status
   ```

### 5. **File Structure Requirements**

#### **Build Output Structure:**
```
dist/
├── manifest.json
├── popup.js                    # ← Must be accessible from popup.html
├── popup.css                   # ← Must be accessible from popup.html
├── background.js              # ← Referenced in manifest
├── content.js                 # ← Injected into pages
├── offscreen.js               # ← Created programmatically
└── src/
    ├── popup/
    │   └── popup.html         # ← Referenced in manifest
    ├── options/
    │   └── options.html       # ← Referenced in manifest
    └── offscreen/
        └── offscreen.html     # ← Created by background script
```

### 6. **Manifest V3 Best Practices**

#### **Essential Permissions:**
```json
{
  "permissions": [
    "activeTab",      // Access current tab
    "scripting",      // Inject content scripts
    "storage",        // Chrome storage APIs
    "offscreen",      // Create offscreen documents
    "notifications"   // Show notifications
  ]
}
```

#### **File References Must Be Correct:**
```json
{
  "background": {
    "service_worker": "background.js"  // ← Must exist in dist/
  },
  "action": {
    "default_popup": "src/popup/popup.html"  // ← Must exist in dist/
  },
  "options_page": "src/options/options.html" // ← Must exist in dist/
}
```

### 7. **Common Silent Failures**

1. **Absolute paths in HTML** → Scripts don't load
2. **Missing files referenced in manifest** → Extension loads but features break
3. **Incorrect permissions** → API calls fail silently
4. **Wrong service worker path** → Background logic doesn't work
5. **CSP violations** → Scripts blocked by content security policy
6. **Missing offscreen HTML files** → `Error: Page failed to load` when creating offscreen documents

#### **Offscreen Document "Page failed to load" Error**
**Symptom:** Background script fails with `Error: Page failed to load` when calling `chrome.offscreen.createDocument()`

**Cause:** The referenced HTML file doesn't exist in the built extension

**Solution:** Ensure build process copies all referenced files:
```bash
# Fix build command to properly copy offscreen files
mkdir dist\src\offscreen & copy src\offscreen\offscreen.html dist\src\offscreen\ /Y
```

#### **Stale Job State Prevention**
**Symptom:** Extension gets stuck reusing failed/old jobs instead of starting fresh analysis

**Cause:** Popup logic reuses any existing job state without checking if it's stale or failed

**Solution:** Add automatic cleanup of stale/failed jobs:
```typescript
// Check if job is stale or failed before reusing
const jobAge = Date.now() - existingState.updatedAt;
const isStale = jobAge > 5 * 60 * 1000; // 5 minutes
const isFailed = existingState.state === 'failed';
const isStuckInQueue = existingState.state === 'queued' && jobAge > 2 * 60 * 1000; // 2 minutes

if (isStale || isFailed || isStuckInQueue) {
  await chrome.storage.local.remove(`job:${this.currentJobKey}`);
  // Continue with fresh analysis
}
```

### 8. **Testing Checklist**

Before deploying Chrome extension:

- [ ] ✅ Extension loads without manifest errors
- [ ] ✅ Popup opens and displays correctly  
- [ ] ✅ Buttons respond to clicks (check console logs)
- [ ] ✅ Background script loads (inspect background page)
- [ ] ✅ Content scripts inject properly (test on web pages)
- [ ] ✅ Storage APIs work (check chrome.storage)
- [ ] ✅ All permissions are minimal but sufficient
- [ ] ✅ File paths are relative (not absolute)
- [ ] ✅ All referenced files exist in dist/

---

## 🎯 **Key Takeaway**

**Chrome extensions are NOT web applications.** They have unique constraints:
- Sandboxed execution context
- Special file loading requirements  
- Manifest-driven architecture
- Different debugging approaches

Always test in the actual extension environment, not just in a web browser!
